# Bhavana Kandikatla — Portfolio

Personal portfolio for Bhavana Kandikatla, a QA Engineer with experience in
end-to-end manual testing, REST API validation and release readiness for
fintech products.

## Tech stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run lint
npm run build
```

## Content

All portfolio content lives in `lib/data.ts`, sourced from the resume. The
downloadable resume is served from `public/Bhavana_Kandikatla_Resume.pdf`.

## Deploy

The project is ready to deploy on Vercel. Import this repository in the Vercel
dashboard and keep the default Next.js build settings.
